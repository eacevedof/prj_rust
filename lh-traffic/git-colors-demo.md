# Guía de Colores de Git en VS Code

Este archivo demuestra cómo aparecen los archivos nuevos (untracked) en el explorador.

## Estados de archivos y sus colores:

- **🟡 Amarillo/Dorado** (`#e2c08d`): Archivos modificados
- **🟢 Verde claro** (`#73c991`): Archivos nuevos (como este)
- **🟢 Verde** (`#81b88b`): Archivos agregados al índice
- **🔴 Rojo** (`#c74e39`): Archivos eliminados
- **🔴 Rojo claro** (`#e4676b`): Archivos en conflicto

## Cómo verlos:

1. Abre el **Explorer** (panel izquierdo)
2. Observa los colores de los archivos
3. Las carpetas padre también se colorean
4. Los badges (M, U, A, D) indican el estado

¡Ahora tu workspace tiene colores de Git habilitados!
